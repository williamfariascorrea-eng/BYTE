# BYTE. — William Corrêa

A personal project gallery with a late-90s terminal aesthetic — the brand hub for the front-end work of **William Corrêa**. Built with plain **HTML, CSS and JavaScript** — no frameworks, no dependencies.

## ✨ Features

- **Retro CRT aesthetic** — green terminal (`#39ff14`) on near-black, scanline overlay
- **Project gallery** — screenshots, stack tags and direct links to each live project
- **Blinking terminal cursor** — pure CSS animation
- **Smooth anchor scrolling** — native `scroll-behavior: smooth`
- **Working contact form** — sends messages by email via **Web3Forms** (no backend)
- **Custom SVG favicon** — terminal-style `>_` mark
- **Fully responsive** — mobile to desktop

## 🛠 Tech Stack

| Concern     | Tool                       |
|-------------|----------------------------|
| Markup      | Semantic HTML5             |
| Styling     | CSS3 (Flexbox, CSS Grid)   |
| Logic       | Vanilla JavaScript (ES6+)  |
| Forms       | Web3Forms API              |
| Hosting     | Vercel (auto-deploy)       |

No build step — open `index.html` and it works.

## 🚀 Getting Started

```bash
# Open the page (double-click index.html or serve the folder)
npx serve .
```
